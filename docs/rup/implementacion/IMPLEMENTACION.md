# Implementación y trazabilidad

El código es la fuente del comportamiento implementado. El [README raíz](../../../README.md) resume la tecnología y los [AGENTS.md](../../../AGENTS.md) fijan las reglas de mantenimiento. El [backlog](../../../AUDIT_REMEDIATION.md) conserva los estados de las correcciones. Los estados de integración siguientes proceden de inspección del código.

## Integración observada

- **Catálogo y venta.** El frontend consulta productos y envía la venta al backend como `CASH`. El POS muestra el QR ilustrativo de Yape/Plin en un panel desplegable y deja pendiente su activación como medio de pago. [Catálogo](../../../frontend/src/AuthenticatedPos.tsx) · [CheckoutModal](../../../frontend/src/components/CheckoutModal.tsx) · [CheckoutYapeSection](../../../frontend/src/components/CheckoutYapeSection.tsx)
- **Inventario y catálogo.** Desde React los ajustes llaman a la API por variante. El formulario crea y edita productos mediante `POST /api/products/catalog` y `PUT /api/products/{id}/catalog`, reservados a ADMIN. El resultado de la API actualiza la pantalla. Las variantes existentes conservan su stock e identidad. [CatalogController](../../../backend/src/main/java/com/shoestore/inventory/product/infrastructure/adapters/in/web/CatalogController.java) · [InventoryView](../../../frontend/src/views/InventoryView.tsx)
- **Acceso e historial.** React recupera la sesión desde el servidor, obtiene el historial diario autorizado y permite anular a ADMIN. El servidor filtra el historial de CASHIER por empleado y comprueba la propiedad en GET /api/sales/{id}. Las ventas históricas sin propietario solo son visibles para ADMIN. El cliente se registra durante la venta. Las métricas de React siguen usando fixtures. [App](../../../frontend/src/App.tsx) · [Cliente HTTP](../../../frontend/src/services/api.ts) · [SessionSecurity](../../../backend/src/main/java/com/shoestore/inventory/shared/config/SessionSecurity.java) · [SaleService](../../../backend/src/main/java/com/shoestore/inventory/sale/application/service/SaleService.java)
